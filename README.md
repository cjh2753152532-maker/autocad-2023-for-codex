# AutoCAD 2023 for Codex

Windows 版 Codex 本地插件，通过 AutoCAD 2023 操作当前图纸，支持三维实体合并、布尔差集和按轴端点创建圆柱。

## 安装

1. 安装并初始化 Codex 桌面端，确认电脑已安装 AutoCAD 2023。
2. 从 [Releases](../../releases/latest) 下载 Windows 安装包并双击运行。
3. 重启 Codex，在 AutoCAD 2023 打开图纸，然后在 Codex 中选用 AutoCAD 2023 插件。

安装器使用已有的 Node.js 或 Codex 运行时。本项目为独立本地插件。
